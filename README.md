# ShopEase - Modern Static E-Commerce Storefront

ShopEase is a modern, responsive static e-commerce web application built using HTML5, CSS3, and Bootstrap 5. It features a clean glassmorphic navigation bar, a product grid showcasing essentials, and an integrated contact form.

## 🚀 Live Demo

You can view the live deployed site here:
[https://github.com/jadendewet18/shopease)


## ✨ Features

- **Responsive Design:** Fully optimized for mobile, tablet, and desktop viewports using Bootstrap's grid system.
- **Modern UI Components:** Styled with custom CSS, Google Fonts (*Plus Jakarta Sans*), and Bootstrap Icons.
- **Product Showcase:** Interactive card layouts with image zoom hover effects and pricing tags.
- **Contact Section:** Integrated horizontal contact layout in the footer.

## 🛠️ Built With

- **HTML5** - Page structure and semantic layout
- **CSS3** - Custom styling and smooth animations
- **Bootstrap 5** - Responsive layout framework and components
- **Bootstrap Icons** - Visual iconography
